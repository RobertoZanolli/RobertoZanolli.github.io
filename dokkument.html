dokkument

a command-line tool for quick access to your documentation links.

dokkument is a CLI tool that allows you to use .dokk files to manage and quickly access important links directly from your terminal. It's designed for developers who want a faster way to open documentation and resources without leaving the command line.

Key Features

  • fast access: open documentation or any link directly from your command line.
  • simple format: uses easy-to-write .dokk files to manage your links.
  • CLI-based: built for developers who live in the terminal.
