This is my first blog post using Hugo! This custom theme matches the style of my main website perfectly.

Why Hugo?

Hugo is a fast and flexible static site generator that makes it easy to manage blog content while keeping the same design as my main site.

Features

  • Fast: Hugo builds sites in milliseconds
  • Simple: Write in Markdown
  • Flexible: Fully customizable themes
